New `core` strings, in English and Polish, for the admin quote-request screen: `rfq.detail.reference.*` (reference price, proposal and difference columns; *price at request* / *current price* / *no price*; *per base unit*) and `rfq.detail.history.*` (history entries, changes, actors, roles, loading, error and truncation notices). Removed: `rfq.detail.column.desired` and `rfq.detail.modify.desiredPrice`, which the screen no longer renders; the proposal column is now labelled by `rfq.detail.reference.column.proposed`.
